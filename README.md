# PrintSvr - 现代化内网局域网共享打印应用平台

基于 **Go 语言** 打造的高性能、跨平台、现代化 **B/S 架构内网共享打印系统**。解决局域网内 Windows 共享打印驱动兼容差、权限繁琐、手机/Mac/跨网段无法便捷打印的痛点。无需配置复杂 Samba 或特定驱动，局域网内的任何电脑、平板或手机只需打开浏览器即可提交并管理打印作业。

---

## 🌟 核心特性

- 🚀 **B/S 现代化架构**：前后端纯原生一体化，静态资源通过 Go `embed.FS` 内嵌打包，**编译为单二进制文件（.exe）**，开箱即用，零外部网络/CDN依赖，在完全断网的内网环境中秒开秒用。
- 👥 **完善的用户系统与权限分权**：
  - **用户端 (User Portal)**：拖拽上传文档、选择目标打印机、配置色彩/单双面/份数/纸张、查看个人打印队列与进度、取消与重打、个人打印配额统计。
  - **管理后台 (Admin Console)**：系统实时大盘（今日任务、待打印、完成率、近7日趋势柱状图、设备负载）、全局队列加急置顶 ⚡ 与调度、用户及配额分配、系统设置与公告管理。
- 🖨️ **物理打印机扫描与仿真调度引擎**：
  - **自动扫描物理设备**：一键枚举 Windows 系统中已安装的物理/虚拟打印机并一键导入；
  - **真实物理打印与仿真模式双轨并行**：支持调用 Windows 原生打印驱动静默执行；同时支持带有真实时间流逝与进度汇报的虚拟仿真模式，即使未接物理打印机也能完整体验全流程；
  - **单机串行保护**：每个打印机设备具有独立互斥调度锁，防止多任务混页卡纸；不同打印机并发协同。
- 📋 **强大的打印队列与状态流转**：
  - 任务状态机：`排队中 (Pending)` ➔ `打印中 (Processing 0~100%)` ➔ `已完成 (Completed)` / `失败 (Failed)` / `已取消 (Cancelled)`；
  - 管理员支持 **加急置顶 (Prioritize)**、强制终止、历史归档一键清理。
- 💾 **轻量纯 Go 数据库**：采用纯 Go 编译的 SQLite 驱动（无 CGO 依赖），零环境配置。

## 🚀 快速启动

### 1. 直接运行现成的可执行文件

在命令行中直接启动服务（默认监听 `8080` 端口）：

```powershell
.\printsvr.exe
```

或者指定自定义端口与存储目录：

```powershell
.\printsvr.exe -port 8088 -data ./mydata
```

启动后控制台将打印局域网访问地址，例如：
```text
==================================================================
   🖨️  PrintSvr - 内网局域网共享打印应用平台已成功启动！
==================================================================
   本地访问地址 : http://localhost:8088
   内网共享地址 : http://192.168.1.102:8088
------------------------------------------------------------------
   默认管理员账号: admin   默认管理员密码: admin123
   默认测试用户:   demo    默认测试密码:   123456
==================================================================
```

### 2. 从源码重新编译

系统已配置纯 Go SQLite 驱动，**不需要安装 gcc 或 CGO**，一键即可编译：

```powershell
go build -o printsvr.exe ./cmd/server
```

## 💻 使用流程说明

### 1. 普通用户端操作
1. 打开浏览器访问 `http://<服务器IP>:8080`；
2. 登录或点击“自主注册”新账号；
3. 进入 **“我要打印”** 页面：
   - 拖拽或选择待打印文件（支持 PDF、Office 文档、图片、TXT 等，最大 50MB）；
   - 点击选择目标打印机；
   - 配置份数、单双面（长边翻转/短边翻转）、黑白/彩色、纸张规格与备注；
   - 点击 **“发送至打印队列”**。
4. 页面自动跳转至 **“我的打印作业”**，实时查看任务进度条从排队、处理中到已完成的全过程；
5. 可在线直接“预览原文件”，或对历史文件执行“重新打印”。

### 2. 管理员控制台操作
1. 使用 `admin` 账号登录，点击右上角 **“进入管理控制台”**；
2. **系统概览**：实时统计今日打印作业数、排队数、完成率、近 7 日趋势分析图表与设备负载；
3. **全局打印队列**：查看全公司/全单位所有人员的打印记录，支持按文件名/流水号检索；排队中的紧急任务可点击 **“⚡ 置顶”** 优先调度，异常任务可强制终止；
4. **打印机管理**：
   - 点击 **“自动扫描 Windows 系统打印机”**，系统自动检测本机安装的物理与虚拟打印机，一键导入；
   - 点击 **“自检测试”** 可即时向指定打印机派发设备自检测试页；
   - 支持自由开启或关闭每台打印机的“仿真模拟模式”与特性标签；
5. **用户与配额管理**：添加新员工账号、调整打印页数额度上限（支持无限额度或定量控制）、启用/禁用账号、一键重置密码；
6. **系统设置**：自定义系统名称、修改首页横幅公告、开关开放注册等。

## 🔒 安全性与生产建议

1. **修改默认密码**：部署到正式内网后，请立即在管理后台或个人设置中修改 `admin` 的初始密码；
2. **自启动守护**：在 Windows 服务器上可通过任务计划程序 (Task Scheduler) 或 NSSM 将 `printsvr.exe` 注册为 Windows 系统服务，随开机自动在后台运行；
3. **防火墙配置**：若局域网内其他电脑无法打开网页，请在服务器的 Windows Defender 防火墙中放行对应端口（如 `8080`）的入站规则。
